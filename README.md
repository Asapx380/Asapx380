## 👨‍💻 Sobre mim

Olá! Me chamo Wesley Luther, sou de Teresina - PI e estou em transição para a área de tecnologia. Atualmente cursando Engenharia de Software, com foco em desenvolvimento front-end e expandindo para o back-end no caminho de me tornar um desenvolvedor full stack.

Aqui no GitHub registro minha evolução, compartilho projetos e aplico melhoria contínua na minha trajetória. 🚀
