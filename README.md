## 🚀 Projeto em Destaque

### 🎟️ Sistema de Sorteios Online (IBPM)
Aplicação web completa desenvolvida e atualmente **em produção**, atendendo usuários reais com transações financeiras em tempo real.

- **Principais Desafios & Soluções Técnicas:**
  - 💳 **Gateway de Pagamento:** Integração com a API do Asaas para geração dinâmica de QR Code PIX e tratamento resiliente de webhooks para confirmação imediata.
  - ⚡ **Realtime Database:** Modelagem de dados e sincronização instantânea de participantes via **Firebase**.
  - 📲 **Automação de Fluxos:** Integração com **Make.com** para envio automático de confirmações e comprovantes.
- **Tech Stack:** JavaScript, HTML5, CSS3, Firebase, Asaas API, Make.com, Git/GitHub.
